### 🧹 클린징 과정

1. **인코딩 변환**: 원본이 CP949 (EUC-KR) → 명시적 디코딩
2. **공백 제거**: `'강습방법 '`, `'OFFLINE       '`, `'남     '` 등 trailing whitespace → `.str.strip()` 적용
3. **잘못된 날짜 제거**: `'2024085'` 같은 형식 오류 → `pd.to_datetime(errors='coerce')` 후 NaT 제거
4. **시간 형식 변환**: 입장시간 `int 2153` → `21:53` (zero-pad 후 시/분 분리)
5. **이상값 제거**: 시(hour) ≥ 24 또는 분(minute) ≥ 60 행 제외
6. **회원번호 0 처리**: 6.9만 건의 익명 입장 → `is_member` 플래그로 구분 보존
7. **체류시간 계산**: 퇴장정보 있는 행만 (0~24시간 범위 내) 유효값으로 처리
8. **파생변수 생성**: 연도, 월, 요일, 연월, 할인율, 유료여부, 강습기간(일)

전처리 결과는 SQLite DB(`bcsports.db.gz`)로 저장. 전체 코드는 `build_db.py` 참조.

### 📊 시각화 결과 (6개 차트)

#### ① 월별 입장객 추이
- **차트**: 막대(총 입장) + 라인(순 방문자) 이중축
- **인사이트**:
  - 2020년 9월 개관했지만 코로나로 실질 운영은 2021년 3월부터
  - 2024년 7월 19,664명으로 역대 최고치 → 안정적 성장세
  - 매년 7~8월(수영장 성수기), 1~2월(겨울 비수기) 계절성 뚜렷
  - 순 방문자 1,300명 수준에서 포화 → 지역 인구 침투 한계

#### ② 요일 × 시간대 입장 히트맵
- **차트**: 2D 히트맵 (YlOrRd 컬러스케일)
- **인사이트**:
  - 평일 오전 6시가 압도적 피크 (수요일 6시 8,933건)
  - 저녁 19~20시 두 번째 피크 → 직장인 퇴근 후 이용
  - 주말은 평일 절반 이하 → 공공체육시설은 '직장인의 일상' 인프라
  - 운영 시사점: 평일 새벽 인력 강화, 주말 가족 프로그램 확대

#### ③ 강습 방식 변화 (온라인 vs 오프라인)
- **차트**: 스택 막대 + 온라인 비중 라인
- **인사이트**:
  - 2020~2021년 온라인 1%대 → 코로나 시기에 오히려 비대면 인프라 부재
  - 2022년 11.8% → 2023년 17.9% 급증 후 2024년 18.0%로 정체
  - 절대 건수는 오프라인 압도적 → 대면 회귀가 명확한 트렌드

#### ④ 강습 매출 구조
- **차트**: 그룹 막대(결제·할인금액) + 유료비율 라인
- **인사이트**:
  - 2022년 결제금액 1,523만원 정점, 2024년 36만원으로 97% 감소
  - 동시에 신청 건수는 2022년 3,254건 → 2023년 5,289건으로 증가
  - 유료 강좌 비율: 2021년 94.4% → 2024년 0.3%
  - 매출 감소 = 운영 실패가 아니라 공공성 강화(무료화) 결과로 추정

#### ⑤ 성별 × 시간대 이용 패턴
- **차트**: 도넛 차트 + 멀티라인
- **인사이트**:
  - 여성 57.2% vs 남성 42.8% → 공공체육시설 주 이용자는 여성
  - 오전 10시 여성:남성 = 2:1 → 주부·은퇴자 수영·아쿠아로빅 추정
  - 저녁 19~21시는 남녀 비슷 → 직장인 공통 이용 시간
  - 정책 시사점: 오전 여성 프로그램 다양화, 저녁 혼성 프로그램 강화

#### ⑥ 강습 등록 → 실제 이용 전환율
- **차트**: 퍼널 차트 (lessons LEFT JOIN entries, 2개 테이블 조인)
- **인사이트**:
  - 6.6%(1,678건)는 강습 등록 후 한 번도 입장하지 않은 '유령 강습생'
  - 강습 1건당 평균 16.4일 이용 (한 달 강좌 기준 출석률 약 55%)
  - 40%는 16회 이상 성실 이용 → 핵심 충성 회원층
  - 무료 강좌 비중이 큰 만큼 출석률 관리 시스템 필요

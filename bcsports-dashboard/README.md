## 🎯 프로젝트 개요

코로나19 직전 개관한 충남 **보령국민체육센터**의 4년치 운영 데이터를 통해
**팬데믹–회복–뉴노멀**을 거친 지방 공공체육시설의 변화를 추적합니다.
이용 패턴·운영 효율·정책적 시사점을 6개 차트로 시각화했습니다.

### 왜 이 주제인가?
- 대도시가 아닌 **지방 중소도시** 공공시설의 변화는 상대적으로 덜 조명됨
- **개관 시점이 코로나 시작 시점과 겹쳐** 자연실험 성격의 데이터
- 단순 이용량이 아니라 **온/오프라인 강습 전환, 매출 구조, 강습-실제 이용 전환율**까지 다면 분석

## 📦 데이터

### 출처
- 공공데이터포털 - 국민체육진흥공단 **공공체육시설이용자현황** (2024-08-31 기준)
- 3개 CSV 파일을 SQLite로 적재

### 테이블 구성 (3개)

| 테이블 | 원본 파일 | 행 수 | 주요 컬럼 |
|--------|----------|------|---------|
| **entries** (입장기록) | 공공체육시설이용자현황_입장기록 | 457,835 | 회원번호, 입장일자, 입장시간, 성별, 퇴장정보 |
| **lessons** (강습이력) | 공공체육시설이용자현황_강습이력 | 25,927 | 회원번호, 강습시작/종료일, 강습방법(온/오프라인) |
| **applications** (강좌신청정보) | 공공체육시설이용자현황_강좌신청정보 | 11,390 | 강좌신청번호, 강습비용, 할인금액, 결제금액 |

### 데이터 클린징 과정

원본 데이터에 다음 이슈들이 있어 전처리를 거쳤습니다.

1. **인코딩 문제**: 모든 CSV가 UTF-8이 아닌 **CP949 (EUC-KR)** 인코딩 → 명시적 디코딩
2. **컬럼명/값의 trailing whitespace**: 예) `'강습방법 '`, `'OFFLINE       '`, `'남     '` → `.str.strip()` 일괄 적용
3. **잘못된 날짜 포맷**: 강습이력에 `'2024085'` 같은 8자리 미만 날짜 → `pd.to_datetime(errors='coerce')` 후 NaT 제거
4. **시간 형식 변환**: 입장시간이 `int` 타입 (예: `2153` → `21:53`) → zero-pad 후 시/분 분리
5. **회원번호 0 (익명 입장)**: 입장기록의 6.9만 건이 회원번호 0 → `is_member` 플래그로 구분 보존
6. **이상 시간값**: 시(hour) >= 24 또는 분(minute) >= 60인 행 제거
7. **퇴장 정보 결측 (1.4%)**: 체류시간 계산 시 유효 데이터만 사용, 0~24시간 범위 벗어나는 값 제외
8. **파생 변수 생성**: 연도, 월, 요일(0=월), 연월, 할인율, 유료여부, 강습기간(일) 등 분석용 컬럼 추가

전체 클린징 코드는 `build_db.py` 참조.

## 📊 시각화 결과 (6개 차트)

### ① 월별 입장객 추이 — 개관·코로나·회복의 4년
- **SQL**: `entries` 테이블을 `ym(연월)` 으로 GROUP BY 후 총 입장 건수와 순 회원수를 동시 집계
- **차트 유형**: 막대 + 보조축 라인 (이중축)
- **인사이트**:
  - 2020년 9월 개관 직후 **코로나19로 실질 운영은 2021년 3월부터**
  - **2024년 7월 19,664명 역대 최고치** 기록, 안정적 성장세
  - 매년 **7~8월(수영장 성수기)** 와 **1~2월(겨울 비수기)** 의 계절성 뚜렷
  - 순 방문자 1,300명 수준 포화 → 지역 인구 침투 한계

### ② 요일 × 시간대 입장 히트맵 — 인력 배치의 최적해
- **SQL**: `dow`(요일) × `entry_hour`(시간) 2D 그룹핑
- **차트 유형**: 히트맵 (YlOrRd 컬러스케일)
- **인사이트**:
  - **평일 오전 6시가 압도적 피크** (수요일 6시 8,933건)
  - **저녁 19~20시 두 번째 피크** (직장인 퇴근 후)
  - 주말은 평일 절반 이하 → **공공체육시설 = 직장인의 일상 인프라**
  - 운영 시사점: 평일 새벽 인력 강화, 주말 가족 프로그램 확대

### ③ 강습 방식 변화 — 비대면 시도와 회귀
- **SQL**: `lessons` 의 `year × method` 그룹핑, 누적 막대 + 온라인 비중 라인
- **차트 유형**: 스택 막대 + 라인
- **인사이트**:
  - 2020~2021년 온라인 비중 1%대 (코로나 시기에 오히려 비대면 인프라 부재)
  - **2022년 11.8% → 2023년 17.9% 급증**, 2024년 18.0%로 안정화
  - 절대 건수는 오프라인이 압도적 → **대면 회귀가 명확한 트렌드**

### ④ 강습 매출 구조 — 유료에서 무료로의 전환
- **SQL**: `applications` 의 연도별 결제금액·할인금액·유료비율 집계
- **차트 유형**: 그룹 막대 + 보조축 라인
- **인사이트**:
  - **2022년 결제금액 1,523만원이 정점**, 2024년 36만원으로 97% 감소
  - 동시에 신청 건수는 **2022년 3,254건 → 2023년 5,289건으로 증가**
  - **유료 강좌 비율: 2021년 94.4% → 2024년 0.3%** → 거의 모든 강좌 무료화
  - 매출 감소 = 운영 실패가 아니라 **공공성 강화의 결과** 추정

### ⑤ 성별 × 시간대 이용 패턴 — 누가 언제 오는가
- **SQL**: `gender × entry_hour` 그룹핑, 도넛(전체비율)과 라인(시간대별) 동시 표시
- **차트 유형**: 도넛 + 멀티라인
- **인사이트**:
  - **여성 57.2% vs 남성 42.8%** — 공공체육시설 주 이용자는 여성
  - **오전 10시 여성:남성 = 2:1** → 주부·은퇴자 수영·아쿠아로빅 추정
  - **저녁 19~21시는 남녀 비슷** → 직장인 공통 이용 시간
  - 정책 시사점: 오전 여성 프로그램 다양화, 저녁 혼성 프로그램 강화

### ⑥ 강습 등록 → 실제 이용 전환율 — '유령 강습생'은 얼마나 될까
- **SQL**: `lessons LEFT JOIN entries ON member_id AND date BETWEEN` — **3개 테이블 중 2개를 회원번호로 조인**한 핵심 분석
- **차트 유형**: 퍼널 차트
- **인사이트**:
  - **6.6%(1,678건)는 강습 등록 후 단 한 번도 입장하지 않은 '유령 강습생'**
  - 강습 1건당 평균 16.4일 이용 (한 달 강좌 기준 출석률 약 55%)
  - 40%는 16회 이상 성실 이용 → 핵심 충성 회원층
  - **무료 강좌 비중이 큰 만큼 출석률 관리 시스템 필요**

## 🚀 로컬 실행 방법

```bash
# 1. 저장소 클론
git clone https://github.com/YOUR-USERNAME/bcsports-dashboard.git
cd bcsports-dashboard

# 2. 의존성 설치
pip install -r requirements.txt

# 3. (선택) 원본 CSV에서 DB 재생성
#    원본 CSV 3개를 입장기록.csv, 강습이력.csv, 강좌신청정보.csv 로 저장 후
python build_db.py

# 4. Streamlit 앱 실행
streamlit run app.py
```
